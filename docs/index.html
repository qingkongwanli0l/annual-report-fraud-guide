从浏览到核查

1. 找联系

围绕异常节点，在图谱中查看关联手法、影响与核查方向。

2. 定路径

在脑图中定位条目，明确需阅读的年报章节与附注。

3. 做核查

统一期间与指标口径，再将报表、附注和经营披露交叉核对。

4. 留边界

区分已披露事实、待核实事项和合理解释，记录信息缺口。

异常信号用于提示进一步核查，不直接构成舞弊结论。具体判断应结合企业业务、适用会计准则和披露情况。
