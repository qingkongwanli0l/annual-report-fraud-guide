# 分析方法

## 阅读与覆盖

完整阅读是逐页获取可读内容并对实际章节进行分析，不是工具成功提取了所有页。先记录真实章节：业务与管理层讨论、治理及激励、审计报告、资产负债表、利润表、现金流量表、权益变动表、会计政策、附注和重大事项。目录或检索结果不能代替正文。报告只引用其他文件时，本任务把被引用内容列为范围缺口。

每个适用规则都要有实际程序或具体缺口。按风险和金额决定深入程度、原页复核范围和报告篇幅，但不能以重要性低为由把尚未检查改成“不适用”。对金融、保险和特殊行业先确认业务及准则，不能机械套用工商企业周转率或准备指标。

单年报告中实际披露的比较数据可以使用；缺少的历史期、季度和后续数据保持缺口。日数按实际报告期间计算。同行和市场价格只有报告内明确载明且口径可核时才可用；管理层引用的数据仍标明是报告陈述，不代表本次外部验证。

## 证据和取数

一个证据记录对应具体 PDF 物理页和定位。跨页表格分别登记各页、完整表头、单位、目标行和列；保留空白列、负数符号及表注。提取矩阵只是候选。扫描页经宿主视觉/OCR读取后，保留原页和核实状态；不能悄悄替换文本却沿用原来的核验结论。

合并、母公司、归母与少数股东不可互换。原报、重述和分析调整分开。金额记录为十进制字符串和单位倍数；总额、准备与净额分别取数。某个总额对得上不能证明组成项正确。管理层解释、审计师意见及分析者判断分别记录。

计算之前核对主体、范围、期间、会计基础、币种和度量。资产负债是时点，收入现金流是期间。缺少真实期初余额时不计算平均余额指标；报告给出的指标值和自行复算值分别保留。不能因为公式可计算就认为经济口径合理。

## 勾稽和分析桥

- 资产 = 负债 + 权益，合并净利润 = 归母净利润 + 少数股东损益。
- 期初现金及等价物 + CFO + CFI + CFF + 汇率等披露变动 = 期末现金及等价物。货币资金、受限资金、可支配资金和现金等价物按原披露连接，不能仅凭名称互换。
- 期初权益 + 综合收益 + 股东投入 - 已确认分配 ± 其他直接权益变动 = 期末权益。拟议分红、宣告分红与实际现金支付分开。
- 资产或准备金按新增、计提、转回、核销、处置、并表、汇兑及重分类逐项滚动。准备余额净变动不等于当期减值损益；转销不能自动当作转回利润。
- 净利润至 CFO 使用报告同一范围净利润及其逐项调节。应收、存货或应付余额差异需先剔除非现金、并购和重分类，不能直接称为经营现金贡献。
- 自由现金流及并购后现金流是明确定义的分析口径，不自动构成法定报表更正。并购付款、继承营运资本、供应商融资和非现金采购应分别解释。

差额先重新从原页独立取数，核对表头、单位、遗漏项、期间、范围与正负号。舍入容差须有披露精度和加总项数依据；不能用收入百分比放大容差或倒挤“其他”归零。等式闭合只证明所取数值关系，不证明交易真实。

## 深入判断

对每个重要疑点依次建立：已披露事实、计算结果、经济机制、支持证据、反证、竞争解释、可能影响、当前判断与改变判断所需证据。可重点连接收入与应收、现金与融资、资本化与未来费用、准备金与利润、并购与增长口径、关联关系与交易实质。

合理替代解释必须用报告内容验证，不能靠罗列可能性消除风险，也不能因为无法排除而认定舞弊。业务收缩、现金紧张、负自由现金流、估计变更和无保留审计意见分别只支持其本身的观察。

风险优先级与证据强度分开：优先级综合金额影响、影响科目、持续性和治理关联；强度取决于披露的直接程度、交叉支持和反证。不得将二者乘出未经校准的舞弊概率。

拟调整或敏感性结果标明税前/税后、期间、范围、条件及来源。只有充分输入时才计算金额区间。相关发现用 `overlap_group` 及交叉引用提示重复影响，不自动汇总为总错报。对于确认条件、价值依据或主观故意不可验证的事项，给出具体证据缺口和后续核查建议，而不伪称已做函证、盘点或访谈。

## 原页复核和报告

关键发现重新核查引文及数字，专门寻找反例和报告其他位置的解释。重新录入的事实另留记录，与原录数差异写入复核说明，修正后不保留已经解决的资料请求。逐项确认“已执行”和“建议执行”的动词准确。

报告先给重要发现与限制，再按专题解释结果，最后列出完整 101 项覆盖、证据、事实和计算。报告中的判断性数值用底稿 ID 插入，不另写第二套金额。审阅 Word 的分页、表格和中文显示。

## 准则与方法适用边界

本包是分析方法，不是 CAS、IFRS、HKFRS 或 US GAAP 的完整准则库。先采用 PDF 明示的会计基础及政策，再核本包规则的业务条件；不按上市地猜会计基础。未经条文与适用版本支持时，使用“与报告自身政策不一致”“在所述条件成立时存在疑点”等准确表达，不能声称已证明违反某准则。监管阈值、行业标准和法定生效日不由模型记忆补入。

一般审慎原则参考 [PCAOB AS 2401](https://pcaobus.org/oversight/standards/auditing-standards/details/AS2401)：异常、错报与故意舞弊须区分，证据需批判性评价。该参考不代表对所有公司的审计准则适用判断。运行分析时不需要访问此链接。
